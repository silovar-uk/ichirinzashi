# 人物記事から「一輪挿し」の思考表現を派生させるプロンプト

## 目的

人物について深く調べた記事を起点に、その人物を形容する言葉ではなく、記事を書くときに使った「人物理解の思考操作」を近代日本語の表現へ変換し、silovar-uk/ichirinzashi に追加できる3表現を選ぶ。

人物評語を増やすことが目的ではない。

「すごい」「努力家」「柔軟」「才能がある」のような評価を古語へ置き換えるのではなく、

- 表面だけで判断しない
- 一つの数字で全体を断じない
- 時系列で変化を見る
- 環境との関係で能力を見る
- 事実と解釈を分ける
- 偶然と因果を混同しない
- 肩書と実態を分ける
- 将来の成功を現在の事実から予言しない

といった操作を、文章で再利用できる形にする。

## 入力

- 起点記事：{{人物記事URLまたは本文}}
- 対象人物：{{人物名}}
- 登録先：silovar-uk/ichirinzashi

## 1. まず人物の特徴ではなく、記事の認識変化を取る

記事について次を整理する。

- 読む前の素朴な見方
- 調査後に変わった見方
- 最初に目立ったラベル
- ラベルでは説明できなかった事実
- 時系列で変化した点
- 環境との相互作用
- 一つの原因へ還元しなかった箇所
- 断定を止めた箇所
- 事実と筆者解釈の境界

## 2. 思考操作へ変換する

人物固有の内容を一段抽象化する。

例：

- 「身長が高い」→目立つ一属性から全体を読まない
- 「海外でプレーが変わった」→環境変化に応じた適応を見る
- 「怪我のあとに成長した」→前後関係を因果関係へ変えない
- 「所属先で名前表記が違う」→表示名と人物実体を混同しない
- 「得点が増えた」→単一指標と役割全体を分ける

## 3. 候補を12〜18個出す

形式を散らす。

A｜単語・熟語・副詞  
B｜慣用句・連語・定型句  
C｜構文・文型

候補は最低でも次の機能群から探す。

- 表面／本質
- 適応／変化
- 根拠の限定
- 因果の留保
- 時系列
- 名称／実質
- 人と環境の関係
- 評価の慎重さ

## 4. Webで一次資料を確認する

優先順位：

1. 青空文庫の本文
2. 国立国会図書館などの原資料
3. 作家・思想家・当事者の原文
4. 渋沢栄一記念財団など史料機関
5. コトバンク掲載の国語辞典
6. 国立国語研究所

各候補について確認する。

- 読み
- 意味
- 近代での実例
- 年代
- 原文中での意味
- 現代語への置換
- 置換すると失われるニュアンス
- 人物へ使ったとき評価を強めすぎないか

## 5. 再調査で必ず落とす

最初に合いそうな語ほど疑う。

最低5候補について不採用理由を残す。

特に次を検査する。

- 人物を褒める方向へ勝手に強めていないか
- 成功物語を後付けしていないか
- 本人の性格を推測していないか
- 一時点の結果を本質扱いしていないか
- 現代でも普通すぎて発見がないか
- 難しいだけの語になっていないか
- 三語の機能が重なっていないか
- 語の本来の文脈が対象人物に失礼でないか

## 6. 最終3表現を選ぶ

原則A・B・Cから1つずつ。

三つを並べると、一つの人物理解の手順になることを優先する。

例：

1. 表面のラベルを疑う
2. 時間と環境の中で変化を見る
3. 一つの根拠からの断定を止める

## 7. JSON化

既存のentries/*.jsonと同じスキーマを使い、1表現1JSONにする。

必須：
- id
- date
- functionTag
- function
- word
- notation
- reading
- gist
- distance
- plain
- swap
- why
- citations
- examples
- oneLine
- caution

原典引用は80字以内。

examplesは、起点人物だけに閉じない。人物記事、組織分析、仕事の振り返りにも使える例を混ぜる。

## 8. 調査メモを保存する

docs/RESEARCH-<PERSON>-RELATED-WORDS-<DATE>.md に次を残す。

- 起点記事
- 記事の認識変化
- 初回候補
- 調査結果
- 採用3表現
- 不採用候補と理由
- 三語を一つの思考手順として使う方法
- 事実と編集判断の境界
- 参照URL

## 9. 登録と検証

- entries/との重複を確認
- 1表現1JSONでmainへ追加
- JSONスキーマを確認
- 青空文庫引用をverify.mjsで照合
- build.mjsで公開対象になることを確認
- GitHub ActionsのPages公開を確認
- 公開後にサイト上で3語を検索して表示を確認

## 10. 完成監査

- 人物の美談を作っていないか
- 事実から性格を推測していないか
- 一つの数字を本質へしていないか
- 語の原典での意味を壊していないか
- 三語の思考機能が異なるか
- 現代文へ一点差しできるか
- その人物を知らない文章でも再利用できるか
- 一輪挿しが人物辞典やサッカー用語集になっていないか
