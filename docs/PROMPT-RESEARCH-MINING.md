# 企業研究から「一輪」を採掘するプロンプト

企業研究・市場調査・競合分析の途中で見つかった論点から、現代の分析文でも使える近代知的文章表現を3つ選び、`silovar-uk/ichirinzashi`へ追加するための補助プロンプトです。

## 目的

調査対象の専門用語を古風に言い換えるのではなく、調査で実際に行った**思考操作**を言語化できる表現を探します。

例：

- 複数資料を比較し、採るべき部分を選ぶ
- 実績・史実・データを証拠として判断する
- 事実と推察を分けて仮説を置く
- 一見した印象を留保して再評価する
- 例外や条件を残して結論を限定する
- 複数の要因の軽重を量る
- 議論の帰着点や今後の成否を示す

## 手順

1. 直前の企業研究・市場調査を読み、そこで使った思考操作を5〜8個抽出する。
2. `data/words.json` または `entries/` を確認し、既存の主役語と重複しないようにする。
3. 明治〜昭和前期の原典を中心に10〜15候補を調べる。
4. 候補ごとに、意味、形式、原典用例、現代の可読性、現代語との差、分析文での用途を確認する。
5. 最終的に3表現へ絞る。原則として「単語系／句系／構文系」をばらけさせる。
6. 青空文庫等の原文で短い引用を確認する。
7. 企業研究の文脈へ自然に差し込んだ現代文例を作る。
8. 既存JSONスキーマのまま、1表現1ファイルで登録する。
9. 登録後、GitHub Actionsの原文照合・Pages公開が成功しているか確認する。

## 選定基準

優先する表現：

- 普通の現代語へ置き換えると、判断の根拠や留保の度合いが失われる
- 「難しい」より「考え方が精密になる」
- 企業研究、戦略、調査、編集で再利用できる
- 現代文へ1か所だけ挿しても意味が通る
- 原典で用例が確認できる

避ける表現：

- 専門用語の古い言い換えにすぎない
- 格調だけが上がり、論理が増えない
- 現代語との差を説明できない
- 既存の一輪と同じ思考操作しかない
- 根拠のない推測を強そうに見せるだけの表現

## 再リサーチ

3語を選んだあと、必ず一度疑う。

- もっと短く自然な表現はないか
- 同義語より、別の思考操作を持つ語を選べているか
- 原典の意味と現代例文で意味がずれていないか
- 企業研究の内容を知らなくても使える語か
- 「その語を知った後、以前より精密に書ける」か

条件を満たさない候補は差し替える。

## 出力の考え方

3語は、できれば一連の思考として並べる。

例：

**材料を集める → 証拠で確かめる → 仮説を置く**

- 参酌
- 〜に徴するに
- 案ずるに

あるいは、

**論点を切る → 軽重を量る → 結論の行方を示す**

のように、3語を覚えることで分析の手順そのものが増える組み合わせを優先する。
