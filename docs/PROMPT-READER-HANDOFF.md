# 読者に一手を渡す近代文章表現プロンプト

## 目的

「余白のあるコピー」の発想を、近代日本語の文章表現へ展開する。

ここでいう余白は、単なる省略や曖昧さではない。

**書き手が意味の骨格を示したうえで、推論・判断・補完の一手だけを読み手へ渡すこと**と定義する。

明治〜昭和前期の小説・随筆・評論・書簡から、そのような働きを持つ語彙・句・構文を調査し、一輪挿しへ追加する。

## 最重要原則

「難しい」「古風」「美しい」だけでは採用しない。

採用する表現は、現代文へ差し込んだときに次のどれかを精密にできるものに限る。

- 含意を残す
- 可能性を閉じない
- 事実と解釈を分ける
- 論点を一時的に脇へ置く
- 読み手に推論させる
- 例外を残して一般化する
- 結論の強さを調整する
- 直接言わず周辺から意味を立ち上げる

## 0. 既存語を確認する

最初に以下を確認する。

- https://silovar-uk.github.io/ichirinzashi/data/words.json
- GitHubの entries/

role=main の既出表現は主役にしない。

## 1. リサーチ

毎回、最初に10〜15候補を集める。

優先資料:

1. 青空文庫の明治〜昭和前期原典
2. 国立国語研究所
3. 国立国会図書館
4. 精選版日本国語大辞典・デジタル大辞泉等を収録する信頼できる辞書
5. 作家・研究機関の一次資料

候補ごとに以下を内部整理する。

- 表現
- 読み
- 形式
- 原典の年代
- 原典での役割
- 現代語への置換
- 置換で失われるもの
- 読み手へ渡している「一手」
- 現代での自然さ
- 時代距離1〜5

## 2. 五つの探索棚

候補を最低でも次の5棚に分ける。

### A. 含意
例: 言外に、含蓄、暗示、余情

### B. 留保
例: なきにしもあらず、無用ではなかろう

### C. 解釈
例: 〜と見るのが至当であろう

### D. 論点保留
例: その当否は別として

### E. 迂回
直接結論を書かず、周辺の像・対比・例から意味を立ち上げる表現。

同じ棚から3つ選ばない。

## 3. 再リサーチ

最終候補を6つまで絞ったら、必ずもう一度原典と辞書へ戻る。

確認事項:

- 本当にその意味で使われているか
- 原典の年代は対象範囲内か
- 引用箇所だけを切り出して意味を誤読していないか
- 現代語との差が説明できるか
- 単なる婉曲・責任回避ではなく、思考精度に寄与するか
- 現代の普通の文章へ一輪だけ挿せるか

条件を満たさないものは差し替える。

## 4. 最終3表現

原則として形式をばらけさせる。

- A: 単語・熟語・副詞
- B: 慣用句・連語・定型句
- C: 構文・文型・文末

1回につきA/B/Cから1つずつが理想。

さらに、3つの「読み手へ渡す仕事」も変える。

例:
- 一つは含意を読む
- 一つは可能性を残す
- 一つは解釈として受け取る

## 5. 採用判定の核心

各候補について、次の文を必ず埋める。

> この表現は、書き手が「______」まで決め、読み手に「______」を一手だけ渡す。

この文を具体的に埋められない表現は採用しない。

## 6. 守破離

### 守
明治〜昭和前期の原典を短く引用する。

- 作者
- 作品
- 年代
- 短い引用
- URL
- その文中で何をしているか

### 破
現代の平易な表現へ置換する。

その結果、次のどれが失われるか説明する。

- 推論
- 留保
- 解釈位置
- 断定の強さ
- 含意
- 距離感
- 読み手の参加

### 離
周囲は完全な現代語のまま、その表現だけを自然に挿した例を作る。

文章全体を古風にしない。

## 7. 却下条件

- ただ曖昧なだけ
- 責任逃れにしかならない
- 難読さしか価値がない
- 美的余韻だけで思考操作がない
- 現代語との差が説明できない
- 例文が古風になりすぎる
- 原典での用法と現代例がずれている
- 現代でも頻出しすぎて学習上の発見が薄い
- 読み手へ何を渡すか説明できない

## 8. JSON登録

既存 entries/*.json と同じスキーマで、1表現1JSON。

ファイル:
entries/<date>-<romaji>.json

必須項目:
- id
- date
- functionTag
- function
- word
- reading
- gist
- distance
- plain
- swap
- why
- citations
- examples
- oneLine
- caution

必要に応じて notation / siblings / refs を使う。

引用は短くし、青空文庫URLを優先する。
