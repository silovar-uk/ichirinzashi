# Private Memo UI 改修から拾う近代知的文章表現
2026-10-03

## 1. リサーチ

起点:
- Secret操作を常時見える位置へ置く
- 狭幅PCでは一覧と本文を同時に押し込まず、作業中の側を主役にする
- Browse / Focus を明示的な作業モードとして扱う
- breakpoint を端末名ではなく可読幅・必要幅から決める

この設計判断を、近代文章語の「思考操作」へ変換して候補を探した。

候補:
- 繁簡
- 簡にして要を得る
- 本位
- 〜を本位とする
- 主客処を易える
- 主客転倒
- 主従
- 取捨
- 取捨分別
- 機宜
- 斟酌
- 本末を分別する
- 緩急宜しきを得る
- 所を得る
- 〜をもって律すべからず

既存登録を確認し、機宜・斟酌・本末を分別する・緩急宜しきを得る・所を得る等は主役候補から除外した。

## 2. 構造化

今回の設計判断を三つに分解した。

### A. 情報量の配分
「狭いから全部縮める」のではなく、本文を厚く、周辺情報を薄くする。
→ 繁簡

### B. 主役の交換
Browse時は一覧、Focus時は本文を主役にする。
→ 主客処を易える

### C. 判断基準の設定
端末カテゴリではなく、可読性や作業状態を基準に breakpoint を決める。
→ 〜を本位とする

三語はそれぞれ、
- 単語
- 成句
- 構文
となり、形式もばらける。

## 3. 再リサーチ

### 繁簡
喜田貞吉「編輯雑感」（1919）で「繁簡宜しきをえず」の実例を確認。
文章や編集物の「詳述と簡略の配分」を評価する語として、UIの情報密度設計へ転用できる。

- 青空文庫: https://www.aozora.gr.jp/cards/001344/files/54442_49938.html
- コトバンク: https://kotobank.jp/word/%E7%B9%81%E7%B0%A1-606166

### 主客処を易える
福澤諭吉「福翁自伝」（1899）で「壹岐と私とは主客処を易えて」の実例を確認。
「主客転倒」のように誤りを批判するのではなく、実質的な主役・脇役の交換を記述できる点を評価した。

- 青空文庫: https://www.aozora.gr.jp/cards/000296/files/1864_61590.html
- コトバンク: https://kotobank.jp/word/%E4%B8%BB%E5%AE%A2%E5%87%A6%E3%82%92%E6%98%93%E3%81%88%E3%82%8B-2048969

### 〜を本位とする
夏目漱石「私の個人主義」（1914）で「私や私の周囲のものを本位として述べる」の実例を確認。
何を判断の中心基準に置くかを露出させる構文として採用した。

- 青空文庫: https://www.aozora.gr.jp/cards/000148/files/772_33100.html
- コトバンク: https://kotobank.jp/word/%E6%9C%AC%E4%BD%8D-631966

### 却下した有力候補
- 簡にして要を得る: 良い表現だが「繁簡」と機能が近く、今回の3語では意味の幅を優先。
- 主客転倒: 「誤って優先順位が逆になる」という否定的評価が強く、意図的なBrowse/Focus切替には不向き。
- 取捨分別: 情報選択には合うが、既存の「本末を分別する」と近く、今回の新規性では一段落ちる。

## 5. 再利用プロンプト

以下を、Web/UI/業務改善の実装後に使う。

```text
直前に行った設計・実装・業務改善を素材として、https://silovar-uk.github.io/ichirinzashi/ に追加できる近代知的文章表現を探してください。

目的は、技術用語を古語へ翻訳することではありません。
今回行った判断を「どんな思考操作だったか」に分解し、それを精密に言語化できる明治〜昭和前期の表現を探してください。

手順:
1. 実装内容を3〜5個の設計判断へ分解する。
2. 各判断について10〜15個の候補語・句・構文をWeb検索する。
3. ichirinzashi の既存 entries と照合し、重複を除く。
4. 青空文庫、国語辞典、国立国会図書館等で近代実例を確認する。
5. 普通の現代語へ置換したとき、何の思考情報が失われるか比較する。
6. 単語系／句系／構文系を原則1つずつ、計3つ選ぶ。
7. 3語の思考機能が同じ方向へ偏っていないか再監査する。
8. 既存JSONスキーマで1表現1ファイルとして登録する。
9. なぜ採用したか、何を却下したかも簡潔に残す。

特に、
- 何を主とし何を従としたか
- 何を残し何を省いたか
- 何を判断基準にしたか
- 状況に応じて何を切り替えたか
- どの程度の詳しさが適切だったか
を表現できる語を高く評価してください。
```
