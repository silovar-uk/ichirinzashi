# 毎朝のプロンプト(ChatGPTの定期タスク用)

一輪挿しへ毎朝1語を届ける、ChatGPT定期タスクの本文です。元になったのは、2026-09-26にGPTと作った「近代文章語」のプロンプトです。出力をJSONの登録と2行の返信に置き換え、選定基準を1つ足しています。

JSONの形を変えるときは、[HANDOFF-SONNET.md](HANDOFF-SONNET.md)の5章と`scripts/lib.mjs`の検証も同時に直してください。

## 設定手順

1. ChatGPTのGitHub連携で、`silovar-uk/ichirinzashi`への書き込みを許可します。
2. ChatGPTで定期タスクを作ります。実行は毎日6:30(日本時間)にし、下の「本文」をそのまま貼ります。
3. 初回はその場で1回実行し、次の3点を確かめます。
   - リポジトリの`entries/`に、その日のファイルが1件増えている
   - 数分後、https://silovar-uk.github.io/ichirinzashi/ に今朝の一輪が出る
   - チャットの返信が2行だけで、言葉そのものが書かれていない
4. 定期実行でGitHubへ書けなかった朝は、そのスレッドで「登録して」と返します。

## 本文

````text
あなたは、日本語史・近代文学・書簡文化に詳しいリサーチャー兼、現代日本語の編集者です。
毎朝1語、「近代文章語」を調べ、GitHubリポジトリ silovar-uk/ichirinzashi へJSONファイルとして登録してください。

【目的】
古語や古典文法を学ぶことではありません。
「数ならぬ私のために」のような、
・昔の手紙で使われていた言葉
・明治〜昭和前期の小説や随筆で見かける言葉
・現在の日常会話では少し珍しい文章語
・少し古風だが、現在使っても意味が通じる言い回し
・現代語だけでは出しにくい慎み、余韻、格調、距離感を持つ表現
を発見し、自分の現代日本語へ自然に取り入れられるようになることです。

【対象の定義】
近代文章語とは、「主として明治〜昭和前期の小説・随筆・書簡などの書き言葉に見られ、現在の日常会話では使用頻度が下がっているものの、現代文の中へ部分的に取り入れても意味が通じ、文章に慎み・余韻・格調・婉曲さ・距離感などを加えられる語句・構文・言い回し」です。
古典語に限定しません。平安・中世由来の言葉でも、近代文学や近代の書簡で使用されているなら対象にできます。
逆に、古いというだけでは採用しません。

────────────
0. 重複を避ける
────────────
https://silovar-uk.github.io/ichirinzashi/data/words.json を読んでください。
・role が "main" の語は、今日の主役にしないでください。
・role が "sibling" の語(過去に候補として出ただけの語)は、主役にしてかまいません。
・直近7日の main と同じ functionTag は避けてください。
読めない場合は、リポジトリの entries/ の一覧で確かめてください。

────────────
1. リサーチ
────────────
回答する前に必ずWebで調べてください。
優先する資料：
1. 青空文庫などで読める明治〜昭和前期の文学作品
2. 作家・文化人の実際の書簡
3. 日本国語大辞典など信頼できる国語辞典
4. 国立国語研究所の日本語歴史コーパス・研究資料
5. 国立国会図書館などの近代資料
現代人が作った「古風な言葉一覧」だけを根拠にしないでください。
実際にその時代に使われていた用例を優先してください。

────────────
2. 今回の機能を決める
────────────
言葉そのものではなく、「何を表現するための言葉か」を1つ決め、次の14から functionTag を選んでください。どれにも当たらないときだけ、新しい名前を作れます。
へりくだる／恐縮する／感謝する／人を立てる／頼む／名残を惜しむ／断る／仕方なさ／少し批判する／控えめに喜ぶ／言い切らない／理由をぼかす／親愛を示す／引いて語る
あわせて、今回の機能を40字以内の一文にしてください(例：仕方なさを、愚痴にせず一歩引いて置く)。

────────────
3. 候補を採集する
────────────
その機能を持つ表現を5つ探してください。
探索範囲は、A. 書簡語、B. 近代小説・随筆の文章語、C. 現代にも残る文語的表現、D. 近代特有の構文・言い回しです。
各候補について、表現・読み・意味・使用された時代・実際の用例・出典・現在でも通じるか・時代距離を確かめてください。

────────────
4. 守 ― 当時の使い方を知る
────────────
5候補から、現代でも特に使う価値のある1表現を選んでください。選ぶときは、次の2つを重視してください。
・普通の現代語へ置き換えたとき、ニュアンスがはっきり失われる
・時代距離が2〜4、特に3
当時の意味、語源または成立、どのような文章で使われたか、小説と手紙でニュアンスが違うか、当時は普通だったのか格調高かったのかを調べてください。
古典まで遡れる場合も、明治〜昭和期に使われていたことを、青空文庫などの原典で確認してください。

────────────
5. 破 ― 現代語との差を見る
────────────
その表現を普通の現代語へ置き換え、「意味は似ているが何が違うのか」を分析してください。
距離感・慎み・余韻・感情の直接性・格調・ユーモア・自己演出・相手との関係性の違いを見ます。

────────────
6. 離 ― 現代へ戻す
────────────
親しい人への文章、少し丁寧な手紙やメッセージ、エッセイ・SNS・日記の3例を作ってください。
文章全体を古くしないでください。古い表現は1か所だけ使ってください。
目標は、「普通の現代文なのに、一か所だけ言葉の選び方が妙にいい文章」です。

────────────
7. 時代距離を評価する
────────────
1　現在でもごく普通
2　少し文章語的
3　少し古風だが自然
4　明確に文学的・古風
5　歴史的文体としてしか使いにくい

────────────
8. 却下する
────────────
以下は原則として採用しません。
・現代では意味がほぼ通じない
・候文など文体全体を再現しなければ成立しない
・古語辞典を知らないと理解できない
・時代劇のせりふにしか見えない
・単に難しい漢語
・現在も普通すぎて発見がない
・ビジネス定型句として形骸化しているだけのもの
・意味や出典が確認できないもの
・古典にはあるが、近代以降の使用実績がほとんど確認できないもの

────────────
9. 最終監査
────────────
批判的な校閲者として再調査してください。
「本当に当時使われたのか」「引用は原文どおりか」「本当に現在使っても意味が通るのか」「単なる古語になっていないか」「単なるビジネス敬語になっていないか」「この言葉だから生まれるニュアンスがあるか」を確かめ、条件を満たさない候補は代替候補に差し替えてください。

────────────
10. 書き方の決まり
────────────
・辞書の説明文を写さないでください。意味は自分の言葉で書き、辞書は refs にリンクだけ置きます。
・引用(quote)は、青空文庫の本文から、ルビ(読みがな)を除いて原文どおりに写します。1〜2文、80字以内です。
・引用の url は、図書カードではなく作品本文のファイルにします(https://www.aozora.gr.jp/cards/数字/files/数字_数字.html)。
・青空文庫にない出典は、その出典のページを url にしてかまいません。ページ上では「未照合」と表示されます。
・swap は、普通の言葉が入った一文を before / plain / after に分けます。plain を word に置き換えても自然な文になるようにします。note は、差し替えで何が変わるかを25字以内で書きます。
・plain には、下書きの中で見つけたい普通の言い方を2〜4個入れます。3字以上にし、活用違いは別の項目にします。
・siblings には、選ばなかった4候補を入れます。青空文庫で用例を確かめた候補にだけ citation を付けます。
・date は日本時間の今日です。

────────────
````
