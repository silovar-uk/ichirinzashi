# Daily English Chunks → 一輪挿し 語彙採掘プロンプト

## 目的
Daily English Chunks の学習内容から英単語を直訳して拾うのではなく、そこで使われている「思考操作」を、現代文にも挿せる近代知的文章表現へ変換する。

## 入力
- 直近5〜10回の chunk-reading
- とくに decision / assumption / evidence / test / uncertainty / next action に関するチャンク

## 手順
1. 各レッスンを「何を考える操作か」に圧縮する。
2. 10〜15個の日本語候補を、単語・句・構文に分散して出す。
3. 青空文庫、国語辞典、学術資料で実在・意味・時代を確認する。
4. 既存 entries と重複する語、単なる専門用語、有名すぎて発見の薄い語を落とす。
5. 最終3語は、思考の異なる局面を担当させる。
6. 各語について「普通の言い方との差」「判断がどう精密になるか」を説明する。
7. 原典引用を照合し、entries/*.json の既存スキーマで登録する。

## 選定軸
- 元レッスンとの接続
- 現代の仕事・分析・日常で再利用できる
- 近代文章に実例がある
- 現代語への単純置換では失われる意味がある
- 3語が同義語にならず、思考の前後をつなぐ

## 今回の型
- 試金石：何を試せば仮説の真価が分かるか
- 予断：証拠より先に結論を置かない
- 見切りをつける：追加情報の価値が薄れたら止める

この3語を「検証する → 先走らない → 止める」という一連の意思決定として扱う。
