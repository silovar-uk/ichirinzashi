# 二瓶有加型「能力が場によって読めるようになる」概念から近代知的文章表現を採掘するプロンプト

更新日: 2026-09-28

## 目的

人物・組織・プロダクトについて、

「本人に能力がある／ない」
「この施策が良い／悪い」

という固定属性の説明から一歩進み、

- 何が後の展開を開いたのか
- どの配置で既存能力が働いたのか
- どの関係の中で初めて価値が成立したのか

を精密に書ける近代知的文章表現を探す。

## 起点となる思考構造

1. Event — 小さな出来事が後の展開を開く。
2. Placement — 既存の能力・要素がふさわしい位置を得る。
3. Relation — 価値・意味が単独ではなく他との関係で成立する。
4. Revaluation — 同じ性質の評価が環境によって反転する。
5. Reuse — 過去の技能が別文脈で再び働く。
6. Timing — 潜在していた能力が時機によって表面化する。

## リサーチ手順

1. 起点文章から、人物固有の出来事ではなく上記の思考構造を抽出する。
2. 各構造につき2候補程度、合計10〜15表現を出す。
3. 候補を最低でも以下へ散らす。
   - 二〜三字の漢語・熟語
   - 四字熟語・故事成語
   - 慣用句・定型句
   - 構文・文章語的連語
4. 青空文庫、国立国会図書館、国語辞典で用例・意味を確認する。
5. 「才能」「適性」「転機」の類語だけになっていないか点検する。
6. 現代語へ置き換えたとき何が失われるかを書く。
7. 最終3表現は、意味だけでなく形式も分散させる。
8. 主役候補が既存entriesと重複していないか確認する。
9. 1表現1JSONで登録する。
10. 採用理由と却下理由をRESEARCH文書へ残す。

## 特に探す表現

### 出来事
- 原因ほど強くないが、後の展開を開いた接続点を示す語
- 偶然性を残したまま転機を記述できる語

### 配置
- 人や能力がふさわしい場所を得る表現
- 能力の優劣より、能力と役割の組み合わせを示す表現

### 関係
- 性質が単独で成立しないことを示す構文
- 「Aとの関係に置いて初めてBといえる」と限定する文章型

### 再評価
- 同じ性質の意味が文脈で変わることを示す表現
- 弱点が単純に長所へ変わった、という美談にしない表現

## 今回の採用例

- 機縁 — 小さな出来事を後の展開の接続点として捉える
- 所を得る — 既存能力がふさわしい配置で働き始める
- 〜との関連において初めて — 価値が関係の中で成立すると限定する

## 却下しやすい候補

- 適材適所: 現代でも一般的すぎる
- 転機: 出来事後の結果をまとめるだけになりやすい
- 水を得た魚: 比喩が強く分析文では軽くなりやすい
- 蔵器待時: 可読性が低く、才能開花の美談へ寄りやすい
- 驥足を展ばす: 能力への評価色が強い
- 文脈依存: 現代的な術語で、近代文章語の採録目的から外れやすい

## 構造化

最終3表現は、独立した単語帳ではなく、

出来事
→ 配置
→ 関係

あるいは、

何が始めたか
→ どこで働いたか
→ なぜその場で意味を持ったか

という一つの思考手順へ組み直せるか確認する。

## 登録ルール

- 1表現1JSON
- entries/<date>-<romaji>.json
- 既存スキーマを変えない
- 1ファイル1コミット
- citationsには近代の原典を優先する
- 現代例は人物固有名詞に依存しすぎず、キャリア・企画・組織・プロダクトへ転用できる形にする
- mainへpush後、GitHub Pagesのbuildを確認する

## 最終監査

- 固定属性の説明から、関係の説明へ進めているか
- 単純な成功物語へ寄せていないか
- 直接原因と機縁を混同していないか
- 能力の高さと、所を得たことを混同していないか
- 「関連において初めて」を単なる硬い言い換えにしていないか
- 3表現の形式・機能が十分にばらけているか
- 現代文へ一点だけ自然に挿せるか
