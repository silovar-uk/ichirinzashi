# RERESEARCH｜二瓶有加関連記事から派生する語の再監査

Date: 2026-09-28

初回候補を「近代の用例」「現代との差」「起点記事との適合」「形式の分散」の4点で再監査した。

## 1. 機縁を残した理由

中谷宇吉郎「実験室の思い出」では、友人の兄の短い助言が研究人生の分岐点になったことを「機縁」と表現している。

この用例は、今回の記事の「一度の出演を単独原因にしない」という編集方針と合う。

「契機」は現代でも一般的で、「転機」は結果として大きく変わった局面を強く示す。一方「機縁」は、出来事そのものより、それが後の展開へつながったことを記述できる。

判断:
採用。

## 2. 所を得るを残した理由

コトバンクの『精選版日本国語大辞典』では、「自分に適した職を得て力を発揮する」という意味が明示されている。

和辻哲郎の用例はさらに広く、ばらばらの要素が「おのおのその所を得て」全体を形づくる。

これは「能力は本人の内部だけでなく、配置によって可視化される」という起点記事の命題へ直結する。

判断:
採用。

## 3. 〜との関連において初めてを残した理由

三木清の1933年の文章では、ある問いが別の根源的問題との関連に置かれて初めて具体的に答えられる、と論じている。

今回必要なのは「AがBを生んだ」という単線因果より、「Aの意味はBとの関係に置かれて初めて成立する」という関係的な文型である。

判断:
採用。

## 4. 却下候補

### 契機

意味は近いが、現代でも一般的で発見が少ない。
「機縁」の方が、直接原因ではなく接続点という距離を残せる。

### 転機

結果として人生や状況が変わった「局面」を示す語。
今回欲しいのは、その転機を生んだ小さな接続点を記述する語なので主役から外した。

### 適材適所

能力と配置の適合という意味は合うが、現代の組織語としてあまりに一般的。
「所を得る」の方が、本人・物・要素がその場所で働き始める動きを含む。

### 水を得た魚

所を得た後の生き生きした状態を強く描写する。
ただし比喩が前景に出すぎ、分析文では軽くなりやすい。

### 時を得る

好機・時勢を得て栄える意味。
二瓶有加の記事には時間要因もあるが、中心は「時」より「場」と「関係」なので外した。

参考:
https://kotobank.jp/word/%E6%99%82%E3%82%92%E5%BE%97%E3%82%8B-582190

### 蔵器待時

「能力を備えながら、発揮するにふさわしい時機を待つ」という意味でテーマには非常に近い。

ただし現代の可読性が低く、今回確認できた資料では近代の一般文章における主役級の用例を十分確保できなかった。語そのものが故事成語として強すぎ、起点記事を「才能が眠っていて時が来た」という美談へ寄せる危険もある。

判断:
今回は見送り。

### 驥足を展ばす

才能を十分に発揮する意味で近いが、「優れた才能」を前提とする評価色が強い。
今回の記事では本人の能力を外部から格付けすることを避けているため不採用。

### 〜にあって初めて

条件限定には使えるが、「〜との関連において初めて」より関係性そのものが弱い。
今回の中心命題には「関連」を明示する型を優先した。

## 5. 再監査後の三語

- 機縁 = 出来事
- 所を得る = 配置
- 〜との関連において初めて = 関係

意味だけでなく形式も、

- 単語
- 慣用句
- 構文

へ分散している。

## 6. 最終確認

- 近代用例: 3件とも青空文庫で確認。
- 現代語との差: 3件とも説明可能。
- 起点記事との一致: 単なる同義語でなく、記事の論理を三層へ分解できる。
- 人物評価の過剰断定: なし。
- 形式の偏り: なし。
- 既存entriesとの重複: GitHub検索で主役登録なしを確認。
